# OverLap site

Marketing page (English, `index.html`), support page and privacy policy for the OverLap iOS app, in en, fr, de, es and it. Plain static HTML served by GitHub Pages from `main`.

- Support: https://overlap.nchez.fr/support.html (`fr/`, `de/`, `es/`, `it/` for the translations, where `index.html` is the support page)
- Privacy: https://overlap.nchez.fr/privacy.html

Edit the HTML directly, keeping the five languages in step.
